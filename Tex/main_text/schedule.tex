\subsection{下一步工作内容}

后续研究工作沿两条线索协同推进。一方面，对第一阶段跨 kernel 重叠工作 DACOS~\pDacos 作阶段性收尾，将其在短序列大模型负载上的方法同面向通用网络及多流依赖选择的扩展整理为期刊论文。另一方面，围绕本报告第~\ref{sec:arch}~节确立的两阶段自适应执行框架，针对第~\ref{sec:issues}~节归纳的四方面问题，按以下四项具体任务推进完整系统实现与端到端验证，与开题报告确立的四项主要研究内容保持严格对应。

\begin{enumerate}[leftmargin=2.4em,itemsep=3pt]
\item \textbf{面向零实测区间划分的解析代价模型精细化。}针对第~\ref{sec:issues}~节第 2 项问题，提升分组模型在复杂共驻场景下的外推精度，使离线阶段能够直接由模型划定有效行数区间与组内配置。具体工作包括：改进含 FlashAttention-2 共驻分组的寄存器耦合建模与核内分阶段驻留修正项，补齐含词嵌入与词表投影分组的时延模型；将 attention 对 L1 缓存容量的敏感度建模为序列长度的连续函数，并将共享内存 carve-out 档位纳入分组配置空间；补充跨越分块边界两侧的非整倍行数测点，在留出样本上检验模型划定区间与配置相对实测最优的时延偏差。

\item \textbf{二维规模网格候选计划表构建与在线自适应执行。}针对第~\ref{sec:issues}~节第 1、4 项问题，完成图~\ref{fig:arch} 在线阶段的完整系统落地。具体工作包括：将敏感度决策分类从 15 个代表性负载扩展至完整的“batch $\times$ 序列长度”二维输入网格；实现共享底层权重与激活缓冲池的预捕获 CUDA Graph 候选计划表及在线查表调度器，定量刻画计划表条目数、显存占用、预热耗时、单次跨桶切换开销与端到端时延损失之间的折中关系；放宽各层同构分组约束，评估跨层异构边处理的潜在增益。

\item \textbf{多卡张量并行中集合通信节点的边处理扩展。}针对第~\ref{sec:issues}~节第 4 项问题，探索将分布式推理中的集合通信作为一类计算图节点纳入统一边级决策空间。当 AllReduce 等通信操作接入层内阶段链时，其两侧连边同样面临同核融合、跨边界串行或重叠交接的机制选择，且为通信预留 SM 会改变相邻矩阵阶段的波量化形态。后续工作将在双卡张量并行配置下构建通信节点与相邻计算阶段的候选交接方式，测量 SM 配额划分对相邻分组时延及 PDL 准入档位的影响，明确通信连边在动态输入规模下的决策类别（不涉及底层通信路由算法设计）。

\item \textbf{统一算子后端增强与连续生成跨规模验证。}针对第~\ref{sec:issues}~节第 1、3、4 项问题，提升底层算子吞吐并完成服务级全指标验证。具体工作包括：将局部就绪边上的同 grid 细粒度事件同步并入统一后端，引入 Hopper 异步 TMA/WGMMA 流水优化大矩阵主循环并压缩 Q 阶段尾部访存耗时；接入完整的多步连续自回归 token 生成通路，在 1B 及 7B/8B 等不同参数规模模型和动态请求负载上系统报告 TTFT、TPOT、P50/P90/P99 分位数时延与全模块消融分析。
\end{enumerate}
