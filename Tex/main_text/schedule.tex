\subsection{现存问题与下一步工作内容}

对照开题确立的完整系统目标，当前工作在机理剖析、解析建模与离线引导规划上已形成闭环，但在四方面仍需进一步深化：其一，面向任意计算图的前端 lowering 与含高寄存器 FlashAttention-2 共驻分组及首尾层分组的代价模型精度尚待完善；其二，面向二维“batch $\times$ 序列长度”输入网格的候选计划表与在线查表执行器尚未工程落地；其三，第四项研究内容（完整框架实现与端到端连续 token 生成验证）尚未正式开启，核内细粒度事件与大矩阵异步流水亦有待并入；其四，跨层异构分组、7B/8B 等更大模型规模及多卡张量并行中的通信节点边处理尚待拓展。

围绕上述现存问题，后续研究工作沿两条线索推进：一方面，收尾第一阶段工作 DACOS~\pDacos，将其在短序列大模型上的方法与面向通用网络及多流依赖选择的扩展整理为期刊论文；另一方面，按以下四项任务推进第二阶段完整系统构建与验证：
\begin{enumerate}[leftmargin=2.4em,itemsep=3pt]
\item \textbf{解析代价模型精细化与前端依赖模块封装。}改进含 FlashAttention-2 共驻分组的寄存器耦合建模与核内分阶段驻留修正项，补齐首尾词嵌入与词表投影分组模型；将 attention 的 L1 敏感度建模为序列长度的连续函数并将共享内存档位纳入配置空间；独立封装面向通用计算图的前端依赖分析与 lowering 模块，在留出行数与非整倍分块边界测点上验证模型自动划分区间的精度。

\item \textbf{二维输入网格候选计划表与在线自适应执行器实现。}正式开启第四项研究内容，将第~\ref{sec:arch}~节架构完整落地：将敏感度决策分类从 15 个代表负载扩展至完整的“batch $\times$ 序列长度”二维网格，构建共享权重与激活缓冲池的预捕获 CUDA Graph 候选计划表及在线查表调度器，定量评估表项规模、显存占用、预热耗时与跨桶切换开销；放宽各层同构约束，探索跨层异构边处理的收益空间。

\item \textbf{多卡张量并行中集合通信节点的边处理扩展。}探索将分布式推理中 AllReduce 等集合通信作为图节点纳入统一边级决策空间：在双卡张量并行配置下构建通信节点与相邻计算阶段的候选交接方式，量化为通信预留 SM 对相邻矩阵波量化与 PDL 准入档位的影响，明确通信连边在动态输入规模下的决策类别（不涉及底层通信路由算法设计）。

\item \textbf{完整框架端到端验证与跨规模性能评估。}将局部就绪边上的同 grid 细粒度事件并入统一后端，引入 Hopper 异步 TMA/WGMMA 流水优化大矩阵主循环并压缩 Q 阶段尾部访存开销；打通完整的多步连续自回归 token 生成通路，在 1B 及 7B/8B 等不同参数规模模型和动态请求负载上系统报告 TTFT、TPOT、P50/P90/P99 分位数时延与全模块消融分析。
\end{enumerate}
