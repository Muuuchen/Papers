\subsection{下一步工作内容}

后续研究工作沿两条脉络推进。一方面，对前期跨 kernel 重叠工作 DACOS（\cDacos）作阶段性收尾，将其在短序列 LLM 负载上的方法与面向通用负载及多流调度的扩展整合为期刊论文。另一方面，围绕本报告确立的自适应执行框架（第~\ref{sec:arch}~节），针对第~\ref{sec:issues}~节归纳的四项局限，推进模型精度提升、全网格自动分桶、底层算子增强以及多模型与多卡通信扩展。具体研究工作组织为以下四项任务，与开题报告确立的四项研究内容保持严格对应。

\begin{enumerate}[leftmargin=2.4em,itemsep=3pt]
\item \textbf{面向全网格自动分桶的代价模型精细化。}针对第~\ref{sec:issues}~节第 2、3 项局限，消除零实测外推在小批量边界点上的局部偏差，使离线阶段能够直接依托解析模型在二维输入规模空间上自动划定区间端点。具体工作包括：改进 FlashAttention-2 与矩阵阶段共驻时的寄存器耦合建模及分阶段驻留修正项，补齐首层词嵌入与末层词表投影分组的解析模型；将 attention 对 L1 缓存容量的敏感度拟合为序列长度的连续函数，并将共享内存 carve-out 档位正式纳入分组配置空间。完成后将在密集留出网格上评估模型自动分桶方案相对逐点实测最优方案的最大遗憾与离线构建加速比。

\item \textbf{二维规模网格计划表构建与跨层异构分组探索。}针对第~\ref{sec:issues}~节第 3 项局限，将当前 12 桶原型扩展为覆盖完整“batch $\times$ 序列长度”动态服务区间的自适应计划表生成系统，并放宽全模型各层同构切分的假设。具体工作包括：基于给定容差阈值自动压缩二维输入空间上的参数型配置桶数，量化桶数规模、显存开销与端到端时延损失的帕累托折中；探索按层或按计算段异构选择边处理方式的收益空间，并在贴近真实线上分布的连续批处理动态请求轨迹上开展压力评测。

\item \textbf{多卡张量并行中通信节点的边处理扩展。}针对第~\ref{sec:issues}~节第 4 项局限，探索将分布式推理中的集合通信节点纳入统一边处理决策空间。当 AllReduce 等跨卡通信作为图节点接入层内阶段链时，其前后连边同样面临同核融合、跨边界串行或重叠交接的选择，且为通信预留 SM 会改变相邻矩阵阶段的波量化形态。后续工作将在双卡张量并行配置下构建通信节点与相邻计算阶段的候选交接范式，量化 SM 配额划分对相邻分组时延及 PDL 准入档位的影响，并明确通信连边在动态输入规模下的决策类别（不涉及底层集合通信路由算法本身的设计）。

\item \textbf{统一算子后端增强与跨模型规模全面评测。}针对第~\ref{sec:issues}~节第 1、4 项局限，提升底层算子绝对吞吐并扩大模型覆盖面。具体工作包括：将局部就绪边（如 Q$\to$A）上的同 grid 细粒度事件同步并入统一后端，挖掘单请求短上下文区间的流水收益；引入 Hopper 异步 TMA/WGMMA 流水优化大行数 GEMM 主循环并压缩 Q 阶段尾部逐元素访存开销，缩小与 cuBLAS 等专用算子库的绝对时延差距；将框架推广至 7B/8B 等更大参数规模模型，完整汇报端到端 TTFT、TPOT、P50/P90/P99 分位数时延及全模块消融分析（待平台开放管理员计数器权限后一并补充指令级停顿归因）。
\end{enumerate}
